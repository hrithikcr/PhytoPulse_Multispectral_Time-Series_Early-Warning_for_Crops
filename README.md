# 🌱 PhytoPulse: Multispectral Time-Series Early Warning for Crops

## Overview

PhytoPulse is an AI-powered crop disease early-warning system designed to help farmers detect potential crop diseases before visible symptoms appear. The system analyzes multispectral vegetation indices, weather parameters, and historical agricultural data using machine learning to predict disease risk up to two weeks in advance.

It provides an interactive web interface for monitoring crop health, enabling timely interventions and supporting precision agriculture.

---

## Features

- 🌾 Early prediction of crop disease risk
- 📊 Analysis using multispectral vegetation indices
- 🌦️ Weather-aware disease forecasting
- 🤖 Machine Learning-based prediction using LightGBM
- 📈 Interactive dashboard for visualization
- ⚡ Fast and accurate crop health assessment
- 🌍 Supports precision agriculture and sustainable farming

## Installation

1. Clone the repository

```bash
git clone https://github.com/hrithikcr/PhytoPulse_Multispectral_Time-Series_Early-Warning_for_Crops.git
```

2. Navigate to the project directory

```bash
cd PhytoPulse
```

3. Create a virtual environment

```bash
python -m venv .venv
```

4. Activate the virtual environment

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run the server

```bash
python manage.py runserver
```

7. Open your browser

```
http://127.0.0.1:8000/
```
